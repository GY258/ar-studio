# AR 滤镜工作室 · 产品需求文档

**版本** v1.0 · 草案
**日期** 2026-07-26
**状态** 待评审
**项目代号** AR Studio（正式名称待定）

---

## 1. 项目概述

### 1.1 一句话定义

一个打开浏览器就能用的 AR 相机滤镜网站，创作者选一个模板、对着摄像头拍、直接下载成片，不需要安装任何软件。

### 1.2 要解决的问题

现有同类展示站（如参考的 unknownreality）只能看不能导出，创作者必须自己录屏，画质差、有系统 UI、竖屏还要二次裁剪。我们把**录制内置**，一键出成片。

### 1.3 商业模式

| 层级 | 内容 | 价格 |
|---|---|---|
| 免费 | 基础模板（云朵落雪等 1–2 个）、无限录制、带水印可关（待定） | $0 |
| 单模板解锁 | 单个付费模板永久使用 | $0.99 / $1.99 |
| 全解锁包（M2） | 所有现有 + 未来新增模板 | 待定 |

**核心增长逻辑**：模板库持续扩充，用户在工作台看到锁着的模板产生解锁欲望。因此**模板的可扩展性是本产品的技术生命线**，第 5 章会展开。

### 1.4 成功指标

| 指标 | 首月目标 |
|---|---|
| 摄像头授权率（访问 → 开启摄像头） | ≥ 45% |
| 录制完成率（开启摄像头 → 下载成片） | ≥ 30% |
| 付费转化率（注册用户 → 付费） | ≥ 3% |
| 移动端可用率（能跑到 25fps 以上） | ≥ 80% |

## 2. 目标用户

**主要用户：短视频创作者**。做 GRWM、日常 vlog、穿搭内容，需要有辨识度的视觉素材。设备以手机为主、笔记本为辅。不懂技术，不接受任何安装步骤。发布平台是 Instagram Reels、TikTok、小红书。

**次要用户：普通尝鲜用户**。从社交平台看到效果点进来玩一次，可能不注册。这部分人是免费模板的目标，也是自然传播的来源，所以**首次体验必须零门槛：不登录也能用免费模板并录制**。

## 4. 功能需求

### 4.1 主页（P0）

主页有很高的设计要求，是品牌门面，详见第 6 章设计规范。

**结构**

| 区块 | 内容 | 要求 |
|---|---|---|
| Hero | 宣言式标题 + 全屏效果视频背景 + 主 CTA「开始创作」 | 视频自动播放、静音、循环；移动端降级为首帧静图，不加载视频 |
| 效果展示 | 模板效果横向轮播，鼠标悬停播放对应视频 | 懒加载，视口外不加载视频 |
| 三步说明 | 选模板 → 对着摄像头拍 → 下载 | 用短动画而非文字堆砌 |
| 模板库预览 | 网格展示，付费模板带价格角标 | 点击直接进工作台该模板 |
| 隐私声明 | 「画面不上传，全部在你的设备上处理」 | 这是真实的技术事实，也是转化的关键说服点，要显著 |
| 页脚 | 法务链接、社交、语言切换 | |

**性能红线**：LCP < 2.5s，Hero 视频不阻塞首屏渲染。

### 4.2 工作台（P0，核心）

**布局**：预览区居中最大化，控制条悬浮在下方，模板选择器在侧边或底部抽屉。

**功能清单**

- **摄像头预览**：默认前置、镜像、1280×720。设备选择下拉（多摄像头用户）。
- **实时特效渲染**：见 5.2 技术方案。
- **模板切换**：点击即换，无需刷新。付费模板显示锁态，点击弹解锁面板。
- **道具拖动**：可拖动改变发射器位置（花洒必须能对准头顶，否则功能不成立）。
- **参数调节**：每个模板暴露 2–4 个滑块，由模板配置定义，不硬编码。
- **画幅切换**：16:9 / 9:16 / 1:1。**首期以 16:9 为主，9:16 排在 M3**。
- **录制**：一键开始 / 停止，停止后弹出预览与下载。最长 60 秒（防内存溢出）。
- **音频**：可选录制麦克风，默认关闭。
- **导出格式**：优先 `video/mp4`，不支持时降级 `video/webm` 并提示用户该格式部分平台无法直传。
- **状态提示**：帧率、人像识别状态、加载进度。识别失败时给出可操作的建议（换个背景 / 打开灯）。

**非功能要求**

- 摄像头权限被拒绝时给出明确的浏览器设置指引，不能只显示报错码。
- 模型加载期间显示进度，不能白屏。
- 切换模板不能丢失已调好的参数（同类参数保留）。

### 4.3 账号系统（P0）

- **Google 一键登录**为唯一首期登录方式。邮箱密码登录不做（增加成本、降低转化、带来密码安全责任）。
- Apple 登录排在 M2（iOS 用户占比高，且 App Store 生态用户习惯）。
- **未登录可用免费模板并录制**。只有解锁付费模板时才要求登录。
- 登录后自动合并本地状态（已调参数、已选模板）。

### 4.4 支付与权益（P0）

- **Stripe Checkout** 托管收银台，不自建支付表单（避免 PCI 合规负担）。
- 一次性买断，非订阅。
- 流程：点击锁定模板 → 若未登录先登录 → 创建 Checkout Session → 跳转 Stripe → 支付成功回跳 → **Webhook 落库发权益** → 前端轮询或刷新拿到权益。
- **权益校验必须在服务端**。付费模板的完整配置（物理参数、素材路径）只有在服务端确认权益后才下发，不能全量打进前端 bundle。这是本产品最容易被白嫖的地方。
- 退款、争议由 Webhook 自动回收权益。
- 支持货币：首期 USD。

### 4.5 用户中心（P1）

已解锁模板列表、订单历史、下载发票、删除账号（GDPR 要求）。

### 4.6 后台（P1）

- 模板 CRUD：上传配置 JSON + 素材，设置价格、排序、上下架。
- 数据看板：日活、授权率、录制数、各模板解锁转化。
- **目标：新增模板不需要发版**。

## 5. 技术方案

### 5.1 架构

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | Next.js 14+ (App Router) + TypeScript | 主页需要 SSR 做 SEO，API Routes 可直接承接 Stripe Webhook，一套代码两种形态 |
| 样式 | Tailwind CSS | 设计规范可直接落成 token |
| 渲染 | Three.js (WebGL2) | 粒子量级需要 GPU，Canvas 2D 不够 |
| 感知 | MediaPipe Tasks Vision | 浏览器端事实标准，人像分割 / 手 / 脸同一套 API |
| 数据库 | PostgreSQL（Neon 或 Supabase） | 关系清晰，权益查询要强一致 |
| 认证 | Auth.js (NextAuth) + Google Provider | 与 Next 集成成本最低 |
| 支付 | Stripe Checkout + Webhook | |
| 对象存储 | Cloudflare R2 + CDN | 模型和素材，带宽零出口费 |
| 分析 | PostHog（自托管或云） | 漏斗分析，隐私友好 |
| 部署 | Docker + Nginx（自有服务器）或 Vercel | 见 9 章 |

### 5.2 渲染管线

```
getUserMedia
  → <video>
  → MediaPipe ImageSegmenter（每视频帧）→ 人像遮罩
  → 降采样为 112×63 占据场 + 模糊 + 时间平滑
  → 粒子系统（CPU 积分，GPU 绘制）
      碰撞：占据场 > 0.5 → 取负梯度为表面法线 → 消除法向速度、保留切向
  → Three.js 合成（视频纹理为背景 / 粒子 / 道具精灵）
  → canvas.captureStream + MediaRecorder → mp4
```

**关键工程点**

- 检测与渲染解耦：分割按视频帧率跑，渲染按 rAF 跑。
- 遮罩必须做时间平滑（`α≈0.45`），单帧分割会闪，直接用会让粒子抽搐。
- 遮罩必须模糊后再求梯度，否则法线逐格跳变，粒子沿人体边缘会抖。
- 粒子池固定容量循环复用，不在循环内分配对象。
- 移动端自动降级：分辨率降到 640×360、粒子上限减半、关闭溅射。

### 5.3 模板系统（可扩展性核心）

**新增模板 = 上传一个 JSON + 素材，不改代码、不发版。**

模板清单 schema：

```jsonc
{
  "slug": "shower",
  "name": { "zh": "花洒", "en": "Shower" },
  "category": "liquid",
  "price_cents": 99,
  "preview": { "poster": "...", "video": "..." },

  "perception": ["segmentation"],        // 需要哪些模型，决定加载什么

  "emitter": {
    "asset": "/t/shower/prop.webp",
    "aspect": 0.60,
    "port": { "x": 0.10, "y": 0.22 },    // 出口相对道具中心
    "band": 0.10,                        // 横向铺开范围
    "draggable": true,
    "default": { "x": 0.0, "y": 0.34 }
  },

  "substance": {
    "gravity": -1750,
    "friction": 0.05,
    "streak": 0.040,
    "color": [0.60, 0.84, 1.0],
    "size": [1.4, 3.0],
    "speed": [420, 620],
    "spread": 0.20,
    "splash": 3,
    "settle": false,
    "twinkle": false
  },

  "controls": [
    { "key": "rate",  "label": { "zh": "流量" }, "min": 100, "max": 2200, "default": 900 },
    { "key": "wind",  "label": { "zh": "风" },   "min": -300, "max": 300, "default": 0 },
    { "key": "stick", "label": { "zh": "黏附" }, "min": 0, "max": 100, "default": 60 }
  ]
}
```

**设计原则**：引擎只认 schema，不认具体模板。加「莲蓬头」和加「咖啡杯」对代码是同一件事。当某个新创意超出 schema 表达能力时，扩展 schema（加字段、加 substance 类型），而不是写 if-else 分支。

**首期模板**

| slug | 名称 | 物质 | 价格 | 状态 |
|---|---|---|---|---|
| cloud | 云朵落雪 | snow | 免费 | P0 |
| shower | 花洒 | water | $0.99 | P0 |
| glass | 水杯 | water | $0.99 | P0 |
| coffee | 咖啡杯 | coffee | $1.99 | P0 |

### 5.4 数据模型

```sql

templates(id, slug, name_json, category, price_cents, config_json,
          preview_json, status, sort_order, created_at)

entitlements(id, user_id, template_id, source, order_id, granted_at, revoked_at)
  UNIQUE(user_id, template_id)

usage_events(id, user_id, template_id, event, meta_json, created_at)
  -- event: view / camera_grant / record_start / record_download / unlock_click
```

### 5.5 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/templates` | 列表。付费模板只返回预览信息和价格，**不返回 config** |
| GET | `/api/templates/:slug/config` | 返回完整配置。服务端校验权益，免费模板直接过 |
| POST | `/api/checkout` | 创建 Stripe Session，返回跳转 URL |
| POST | `/api/webhooks/stripe` | 验签、幂等落单、发放权益 |
| GET | `/api/me` | 用户信息 + 已解锁 slug 列表 |
| DELETE | `/api/me` | 删除账号（GDPR） |
| POST | `/api/events` | 埋点上报，批量 |

### 5.6 静态资源

**模型和 wasm 必须自托管。** 现在依赖 `storage.googleapis.com` 和 `jsdelivr`，国内访问不稳定甚至不通。全部下载到 R2，走自有 CDN，配 1 年缓存 + 内容哈希文件名。

## 6. 设计规范

### 6.1 参考方向

参考 vxmediagroup.com。从其结构可确认的语言特征：

- 宣言式超大字标题，多行递进，末行加重收尾
- 单词跨行拆分（`Crea` / `tors.`），滚动时产生动态排版
- 整幅动态封面开场，视频即内容
- 导航极简，logo 居中，右侧只有一个 CTA
- 案例用弹层展开而非跳页，保持浏览连续性
- 横向卡片轮播 + 显式箭头

**我们要继承的是它的气质：编辑设计式的克制 + 大胆的字号对比 + 内容本身即视觉。不继承它的具体色彩和素材。**

### 6.2 具体规范

**排版**

字体：标题用一款窄体无衬线（推荐 `PP Neue Montreal` / `Söhne` / 开源可用 `Inter Tight`），正文同族常规字重。中文用 `PingFang SC` / `HarmonyOS Sans`。

字号阶梯，对比要拉开，中间层级少而狠：

| 用途 | 桌面 | 移动 | 字重 | 字距 |
|---|---|---|---|---|
| Hero 标题 | `clamp(56px, 9vw, 148px)` | 44px | 500 | -0.03em |
| 区块标题 | 48px | 32px | 500 | -0.02em |
| 卡片标题 | 20px | 18px | 500 | -0.01em |
| 正文 | 16px | 15px | 400 | 0 |
| 标注 / 数据 | 12px 等宽 | 11px | 400 | 0.06em |

行高：标题 0.92–1.0（贴紧，这是气质来源），正文 1.7。

**色彩**

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0B0D` | 主背景 |
| `--surface` | `#151518` | 卡片 |
| `--line` | `#26262C` | 分隔 |
| `--fg` | `#F2F0EC` | 主文字（偏暖白，纯白太刺） |
| `--muted` | `#8A8A93` | 次要文字 |
| `--accent` | `#C9A0FF` | 主操作、选中态 |
| `--gold` | `#F0C674` | 付费 / 解锁 |
| `--rec` | `#FF5A52` | 录制中 |

深色为主。理由：预览区是摄像头画面，深色界面不干扰色彩判断；同时符合创作工具的调性。

**布局**

12 栏网格，间距用 4px 基数（4/8/12/16/24/32/48/64/96）。区块间距桌面 96–128px，移动 56–72px。内容最大宽 1280px，Hero 和展示区允许全出血。

**动效**

- 缓动统一 `cubic-bezier(.22,1,.36,1)`，时长 200–400ms。
- 滚动进入用位移 + 淡入（16px 上移），不用缩放不用旋转。
- Hero 文字入场按行错开 60ms。
- 悬停状态必须有，但幅度小（边框亮度变化、1–2px 位移）。
- **必须响应 `prefers-reduced-motion`**，关闭所有非必要动效。

**组件**

- 按钮：胶囊形，主按钮实心 accent，次按钮描边。高度 44px（移动端触控下限）。
- 模板卡片：4:5 竖版预览，悬停播放视频，右上角价格角标。
- 锁定态：预览降透明度到 42% + 金色价签，不要用挂锁图标（廉价）。

**可访问性**

正文对比度 ≥ 4.5:1，大字 ≥ 3:1。所有交互元素有 `:focus-visible` 描边。轮播提供键盘操作。视频有描述性 `aria-label`。

## 8. 安全与合规

- **摄像头画面全程不离开设备**，不上传、不落盘、不经服务器。这既是隐私承诺也是核心卖点，必须在首页和工作台显著说明，并写进隐私政策。
- 权益校验全部在服务端，前端状态仅作 UI 提示。
- Stripe Webhook 必须验签 + 幂等（同一 `event.id` 只处理一次）。
- 未成年人：服务条款声明面向 16 岁以上，不主动收集未成年人信息。
- GDPR / CCPA：提供数据导出与账号删除；Cookie 同意横幅（分析类默认关闭，需明示同意）。
- 录制内容归用户所有，平台不留存、不获取任何授权。
- 速率限制：`/api/checkout` 与 `/api/events` 按 IP + 用户限流。

## 9. 部署与运维

**方案 A（推荐，快）**：Vercel 托管前端与 API，Neon 托管 Postgres，R2 存资源。零运维，自动 HTTPS 和全球 CDN。

**方案 B（自有服务器）**：Docker Compose 跑 Next.js + Postgres，Nginx 反代，Certbot 签证书，Cloudflare 挡在前面做 CDN 和 DDoS 防护。

**两方案共同的硬性要求**

- 必须 HTTPS。`getUserMedia` 在非安全上下文直接不可用，这不是可选项。
- 静态资源与模型走 CDN，配长缓存。
- 环境变量：`GOOGLE_CLIENT_ID/SECRET`、`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`、`DATABASE_URL`、`NEXTAUTH_SECRET`。全部走密钥管理，不进仓库。
- 监控：Sentry 收前端异常（重点看不同机型的 WebGL 与 MediaRecorder 报错），Uptime 探活。
- 备份：数据库每日自动备份，保留 30 天。

## 10. 里程碑
