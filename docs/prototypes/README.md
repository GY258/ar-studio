# 原型

单文件可运行原型，用于验证技术可行性。正式代码在 `src/engine/`，这里留作渲染逻辑的参考实现。

- `snowfall-collision.html` — 人像分割 + 落雪碰撞堆积。带一层积雪深度场（正式引擎里暂时没做，见下）。
- `ar-studio-v2.html` — 可切换道具 + 液体物理 + 解锁桩 + 录制。其中的 `SUBSTANCE` 和 `EMITTERS` 两张表就是模板 schema 的雏形。
- `ar-camera-filter.html` — 手部关键点追踪 + 三种粒子特效。**没有收进仓库**（沙箱权限限制），原件在 `~/Downloads/`。M4 做手部类模板时需要它。

## 原型里有、正式引擎里还没有的

`snowfall-collision.html` 里做了一层**积雪深度场**：粒子撞上人体后按法线朝上的程度往格子里沉积，碰撞读的是「人像 + 积雪」的合成场，所以雪堆是往上长的；每格算支撑，人一走开那片雪会塌掉。

正式引擎目前只做到 `substance.settle`（撞上后短暂驻留），没有深度积累。要做的话是给 schema 加一个 `accumulation` 字段，而不是在引擎里给雪写分支。
