# Gotchas

手写。装那些跨文件、看单个文件推不出来、不知道就要浪费一小时的事实。
每条先写症状再写规则——遇到症状时才会想起来查。

## 定位与镜像

**镜像约定分两套，别混。**

「世界坐标 → 场」这一套带镜像：`OccupancyField.at()` 用 `u = 0.5 - wx/w`，
元素定位用 `cx = (0.5 - lm.x) * W`。它们和背景平面的 `bg.scale.x = -1` 成对，改一个要改另一个。

「uv → 纹理」这一套**不带**镜像：马赛克 shader 里 `videoTex` 和 `maskTex` 同在视频空间，
用同一个 `vUv` 取样就对了。平面的 `scale.x = -1` 会把两者一起翻，shader 里再翻蒙版就翻反了。

> 症状：人在画面偏左时，清晰区跑到右边去；人越靠边越明显，正好站中间时几乎看不出来。
> 验的时候一定要用偏心的画面（`--fixture side`），居中的画面对这个 bug 免疫。

> 另一个坑：用「局部方差高 = 清晰」去自动判定会误判。人脸轮廓和五官本身就是强边缘，
> 打了马赛克方差照样高。要么肉眼看，要么和未加效果的原帧逐像素比。

**`size.ref` 与 `anchor.space` 正交。** `face` 锚定 + `vw` 尺寸是合法且常用的组合，
含义是「跟着脸平移但按屏幕定大小」。反过来也合法。

> 症状：人往后退，贴纸跟着缩成一个点（该用 `vw` 却用了 `iod`）；
> 或者人凑近时贴纸没跟着放大（该用 `iod` 却用了 `vw`）。
> 用 `--fixture far` 渲一张就能看出来。

**`anchor.offset` 的单位是 IOD，不是像素、也不是 `size.ref` 那个参照物。**
y 为正表示向下。偏移会跟着头部 roll 一起旋转。

**文字的 `size.scale` 是字号，不是宽度。** 宽度由内容长度决定。
svg 和 gradient 的 `size.scale` 才是宽度。

> 症状：给一段长文字设了 `scale: 0.07` 结果它比预想的宽得多——那是对的，
> 0.07 是字号占屏宽的比例，十个字就有十个字那么宽。

## 分割与帧效果

**`ingest()` 用四角采样定背景值**，因为不同 MediaPipe 版本里「人」编码成 0 还是非 0 不一致。
贴墙拍、人占满四角时这个假设会破，那时候把 `bgVal` 写死成实测值。

**`field.seen` 的语义是「见过人」，不是「收到过一帧 mask」。**
空场景也会 ingest 成功，所以 `seen` 是按占据格子数判定的（>0.5%）。
帧效果的 `onLost` 兜底完全依赖这一点。

> 症状：人走出画面后背景还糊着，或者反过来，有人时却按丢失处理了。

**自定义 shader 必须自己补 `#include <colorspace_fragment>`。**
纹理标了 `SRGBColorSpace`，采样时硬件已经把 sRGB 转成线性；内置材质会在输出端转回来，
裸 `ShaderMaterial` 不会。少这一行，只要帧效果一开整幅画面就整体压暗（实测 232 → 206）。

> 症状：切到带 `source` 的模板画面就发暗发闷，切回去就正常。
> 因为是全画面均匀变暗，不像 bug 更像「滤镜风格」，很容易被当成设计意图放过去。

**蒙版分辨率别复用占据场。** `OccupancyField` 是 112×63，为粒子碰撞设计（粗且重平滑）。
MediaPipe 实际输出的 categoryMask 和输入同分辨率（实测 960×540），
拿占据场当抠图蒙版等于把格子砍掉 74 倍，边缘只剩台阶。帧效果走 `MaskField`，
它保留到 512 长边并只做轻量平滑。

**`source.effect.blocks` 是短边格数**，长边按视口比例给更多格，块才是正方形。
两个轴都用同一个数会得到被拉长的矩形块。视口比例变了要重算，`resize()` 里做了。

**`blocks` 和菜单文案上的「240p」没有换算关系。** 不要试图把两者对应起来。

## 生成器与确定性

**生成器的 id 必须确定。** `expandGenerators()` 每次调用把计数器归零，
同一份 JSON 重复展开产出同一串 id。以前用的是模块级 `globalCounter`，跨模板累加永不重置，
同一个模板在不同加载顺序下拿到不同 id。

> 症状：L2 的 golden 对比时好时坏，重跑一次结果就变了。

**`scatter` 必须带 `seed`。** 理由同上。

**`trail` 的相位差写 `phaseShift`（秒），不是逐个手填 `phase`。**
展开时按 `phase_i = base + i * phaseShift / period` 换算。

> 历史坑：v1 的相位序号是从 id 字符串末位取的（`id.slice(-1)`），
> 改个名字动画就坏，生成器产出的 `tear-17` 末位是 7，相位完全是碰运气。

## 动画

**`fall` 走的是整屏高度，与锚点的 `ny` 无关。** 它返回一个绝对 y 覆盖锚点算出来的位置。
`float` / `pulse` / `emit-fall-fade` 才是相对锚点的位移。

**`float` 和 `pulse` 是正弦，半周期正好回到起点。** 想验「动画在动」要取 P/4 不是 P/2。

**周期不一定闭合。** 一个模板里若干动画的 period 两两互质时（雨滴有 20 多个不同 period），
根本不存在可用的公共周期，L2 会显式跳过「周期闭合」断言并在报告里注明。

## 渲染

**`gl.lineWidth` 在 Chrome/ANGLE 上恒等于 1**，所以粒子液体不能用 `LineSegments` 画。

**cover 模式的比例。** 摄像头用原生比例，`bg` 缩放到覆盖视口。
占据场用的是 cover 后的 `bgW × bgH`，不是视口尺寸。

**离线截图依赖 `preserveDrawingBuffer: true`。** 关掉的话 `canvas.toDataURL()`
在 render 之后拿到的是空白帧，而且不报错。

## 规矩

**素材 SVG 一律拒收而非静默清洗**：`script` / `foreignObject` / `on*` 事件属性 /
外链 `href` / `style` 里的 `url(` 外链。LLM 需要看到报错才能改。

**引擎里不允许出现 `if (slug === "...")`。** 想加这一行说明 schema 缺了一个维度。

**单模板展开后元素数硬上限 120。**

**粒子碰撞阻尼。** 撞到人的粒子速度乘 0.6 并缩短寿命（非沉降类 1~2s）。
这防住了水花乱飞，代价是靠近人的地方特效消散得更快。
